# 赛道 Profile 格式

Profile 保存一个账号或赛道当前稳定的判断，历史过程另存。文件保持短小，新判断与旧判断冲突时覆盖旧值。

```markdown
# 赛道 Profile

## 账号目标
- 赛道：
- 内容定位：
- 商业目标：

## 目标用户
- 核心用户：
- 用户阶段：
- 高频场景：
- 核心痛点和目标：

## 默认筛选
- 平台：小红书
- 时间窗：
- 点赞门槛：
- 其他互动门槛：
- 内容形式：

## 已确认判断
- 正例特征：
- 排除特征：
- 链接与归档要求：

## 外部数据
- 参考库路径：
- 语料台账路径：
- 归档目标：
```

只保留当前会改变搜索和筛选结果的内容。具体笔记、完整搜索词、聊天原话和历次运行记录不写入 Profile。
