# 交付与归档

## 候选校准

第一批候选只提供：标题链接、卡片日期、主要互动指标、初步目标用户和一句入选原因。请用户标记“对 / 相关但不对 / 人群不对”。

## 最终搜索结果

根据 Brief 选择字段，常用结构为：

| 分类 | 标题与链接 | 发布日期 | 形式/时长 | 点赞 | 收藏 | 评论 | Tag | 入选理由 |
|---|---|---|---|---:|---:|---:|---|---|

- 标题作为可点击链接。
- 数据注明核验日期；不可见字段写“未显示”。
- 视频时长使用播放器实际总时长，分类边界由 Brief 或 Profile 决定。
- 入选理由说明目标用户、场景问题和内容任务，不只评价数据。

结果后附：重复项、代表性排除项和覆盖缺口。用户明确只要链接时，内部仍完成必要核验，对外只给分类后的标题链接。

## 归档

写入任何表格或外部系统前：

1. 读取目标表的真实字段，不假设固定表结构。
2. 按规范化链接再次去重。
3. 确认链接在用户要求的设备上可打开。
4. 只补齐目标表要求的字段和图片。
5. 无法取得的值标记“未核实”，并向用户报告。
