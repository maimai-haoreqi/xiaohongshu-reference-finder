# 反馈与语料沉淀

只有用户明确要求沉淀时执行。

## 处理纠正

用户提供理想或漏检笔记时，记录的不只是链接：

- 它实际吸引谁。
- 命中了什么场景与任务。
- 哪个标题词、Tag 或用户自称使它能被发现。
- 为什么原搜索漏掉。
- 哪条搜索或筛选规则需要变化。

用户否定候选时记录拒绝原因：人群、场景、数据、时间、形式、商业任务或表达方式。

## 分层保存

- **当前稳定判断**：覆盖更新外部 Profile。
- **正反例与用户原话**：追加到外部结构化语料库。
- **单次观察**：保留在当次运行记录，未验证前不升级为规则。
- **发布结果**：关联使用的参考和迁移机制，再决定是否调整筛选权重。

Skill 本体只保存跨赛道稳定流程。不得把赛道关键词、笔记清单、聊天历史或不断增长的台账追加到 Skill 与默认 references。
